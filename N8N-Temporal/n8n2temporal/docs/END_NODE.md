# 结束节点

## 定义
- 类型：`*.end`
- 作用：作为工作流的终止节点，标记流程结束并返回最终状态。

## 节点定义示例
```json
{
  "id": "end-node",
  "name": "结束节点",
  "type": "*.end",
  "version": 1,
  "is_remote": false,
  "parameters_source": "",
  "parameters": {}
}
```

### 字段说明
- `id`：节点唯一标识。
- `name`：节点名称。
- `type`：节点类型，结束节点使用 `*.end`。
- `version`：节点版本号。
- `is_remote`：必须为 `false`。
- `parameters_source`：仅远程节点可用，结束节点必须为空字符串。
- `parameters`：无业务参数。

## 参数
- 无。

## 实现逻辑
- 返回空数据集，表示流程结束。

## 行为细节
- 结束节点不改变上下文，主要用于可视化与状态闭合。

## 示例
- 连接至任意分支的终点，执行后返回空结果。

## 错误与边界
- 不依赖上游数据，不产生错误输出。

## 集成点
- 工作流引擎识别结束节点并停止后续调度。
